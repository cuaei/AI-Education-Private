這只是練習示例，正式綜合實作題目、評分及平台上傳尚未開放。此示例不計分，也不能用來解鎖模擬實習。

## 需要

本機安裝 JDK 17 或以上。打開終端機，切換至本項目所在目錄後，在 Windows PowerShell 運行：

```powershell
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```
