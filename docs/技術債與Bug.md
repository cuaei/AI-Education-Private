# AI補練與操作回饋修正

2026-10-12。使用者要求先修正AI安排與錯誤／等待提示；首次登入聚焦教程只交付方案。

## 原因與修正

原先 `/learning/plan` 對任何進行中題目直接回傳，包括 `source=basic` 的基礎題；前端只說「學習記錄已保存」，沒有告知本次沒有調用AI。只讀現有記錄可見基礎練習、未見該記錄的AI安排事件；源碼中的提前返回路徑也會產生這個結果。本輪沒有發送付費模型請求來重現。

現在明確區分：

- 已有基礎題：允許調用AI規劃。AI真正成功建立同技能新題後，私人草稿才替換舊題；原作答歷史保留。AI失敗、格式／證據不合或材料過期時不替換；只是提出辨別問題時也不放棄原題。
- 已有AI題：不重複付費生成，告知原因並定位到題目。
- 需要方法：提示補充步驟，保存後自動接續安排；不用再猜還要按哪一個按鈕。若AI仍需辨別其他錯誤，繼續清楚顯示追問。
- 模型沒有完成必需工具：回傳 `no_action`，不能顯示安排成功；原題保留。
- 從側欄打開補練：重新讀取學習記錄，避免基礎題已建立但主課程版本未變時，介面沒有更新。

規劃提示版本更新為 `personalized-2026.10.12.2`。未改主課程分數、帳號、API密鑰或獨立階段限制。

## 統一操作提示

新增全站操作回饋元件，登入、註冊、提交、AI規劃／解釋／答疑都能顯示處理狀態。等待AI時顯示任務和已等待時間，不顯示虛構百分比或內部推理。通用API等待上限5分鐘，超時說明結果可能已保存，要求先查看記錄；註冊維持原本單次請求與20秒等待界線。

服務端格式／權限／狀態錯誤、網路或JSON錯誤、HTTP成功但模型任務失敗，都有可見提示。補練空答案、非數字、未選選項、空計算步驟和空提問給清楚的修正方向；題目作答未通過沿用回饋彈窗。註冊欄位原有逐項錯誤提示仍保留，另接入統一通知。

提示按操作發生，不在每打一個字時彈窗。語義內容是否正確仍由課程核驗／教練判斷，不能聲稱程式能判斷任意輸入的所有錯誤。已限制重複提示並排隊顯示，完成通知不能蓋掉未確認的錯誤。

## 待人工驗收

以下均未自動執行，實際結果待使用者填寫：

1. 有基礎题時按AI安排：應見等待，再見AI題或方法追問；不能靜默回傳基礎題。失敗時原題仍在。
2. 有AI題時再安排：明確說明已有題、定位題目，沒有新模型請求。
3. 保存方法：先保存，再自動請求規劃；方法保存成功而模型失敗時，兩者狀態清楚分開。
4. 輸入空白、非數字或錯誤選項：未發送／未通過的區別清楚，原填寫內容保留。
5. 錯誤CSV、JSON、登入及註冊：說明格式或欄位原因，不只讓頁面沒有反應。
6. 模型回傳錯誤、超時或尚未完成行動：明確通知，不以HTTP200當作AI成功。
7. 展開／收起、由知識卡建立題再打開、換項目、工程獨立階段：回饋可見，資料及限制不混淆。
8. 手機、鍵盤關閉彈窗、同時有回饋及AI等待：通知可讀、可關閉，不清除學生輸入。

語法／前端構建與服務啟動記錄見 `registration-deployment-status.md` 追加記錄。沒有執行自動行為測試、瀏覽器操作或付費模型驗收，構建不能代替它們。
