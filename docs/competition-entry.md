# 作品名称

实战起点——AI岗位实训Agent

# 作品简介

实战起点是一款面向大学生的AI岗位实训Agent平台，帮助学生将专业知识转化为可交付的岗位作品。学生可按专业选择销售分析与运营建议、软件工程两类实训，分别完成数据清洗、指标分析与运营报告，或校园活动报名系统的需求分析、缺陷修复、前后端开发与测试交付。
平台基于DeepSeek模型与自研任务工具构建Agent，将能力诊断、任务推进、主动答疑、错误分析、个性化补练、作品评审和技术答辩贯穿实训流程。学生遇到困难时可连续提问；提交错误或未获满分时，系统展示核验结果、扣分依据和改进方向，并由Agent结合当前作品提供辅导。数据与程序运行由确定性工具核验，AI评价引用实际提交证据，过程按项目和版本保存。
平台通过独立需求变更观察能力迁移，区分独立完成与AI协作，最终输出源码或分析作品集及学习过程记录。项目采用学生主导的一人工作室服务模式，整合任务包、自动核验、AI辅导和运营后台，帮助创业者管理学员进度、人工复核与模型费用，实现从实训服务到成果交付的完整流程。
