# AI Agent 实现与 API 接入说明

## 项目中的 AI 职责

目标是让一位学生创业者交付有过程记录、反馈与作品的实训服务。模型负责理解和教学判断；项目负责核验、执行与保存。当前实现是一个受控教练 Agent，按用途切换提示和工具白名单。

| 职责 | 提供给 AI 的材料 | AI 要做的工作 | 项目执行的动作 |
| --- | --- | --- | --- |
| 起点诊断 | 首次测评成绩、薄弱技能、当前阶段 | 解释薄弱点，提出符合先修条件的训练顺序 | propose_next_task 保存下一步；必要时 request_human_review |
| 错误辅导 | 最新提交核验、错误标签、课程知识卡 | 判断错误原因，检索知识卡，安排对应补练，逐步提示 | lookup_skill_card 读取；assign_remediation 创建可作答练习 |
| 报告审阅 | 学生原文、已核验指标与图表证据 | 按五项量表评价观察、证据、行动、验证、限制 | review_report 保存带原文摘录的 25 分训练评价 |
| 作品答辩 | 固定作品快照、已答原文及证据 | 提出本人作品相关追问；三题回答后按三项量表评价 | ask_defense_question 保存问题；review_defense 保存 15 分训练评价 |
| 作品整理 | 已有作品、迁移结果、真实协作记录 | 建议如何展示作品和说明贡献，不编造经历 | build_portfolio 返回真实成果；建议由学生确认后保存 |
| 运营助理 | 匿名学员进度、人工复核数量、时间和模型费用汇总 | 提出介入优先次序与课程改进意见 | operator_insights 读取汇总；保存运营建议，不能自动联系或收费 |

无需六个模型。按目的指定不同提示、上下文和工具即可。界面上明确有这些调用入口，服务端位于 backend/main.py，真实模型循环位于 backend/agent.py。

## API key 用在何处

API key 仅作为 HTTP 请求的服务端 Authorization 凭证。它不承担训练流程、课程记忆或工具执行，这些由本项目代码实现。供应商服务器运行大语言模型，本项目运行 Agent。

```text
学生点击「请教练审阅」
  → 浏览器向本项目 /api/coach 提交 purpose=report
  → 后端验证登录、报告与当前数据版本
  → 从 SQLite 取得该学生的必要证据
  → 后端携带 API key 调用供应商 /chat/completions
  → 模型返回 review_report 的参数
  → 后端验证量表、真实原文、证据与分值，并在草稿状态执行
  → 把执行结果以 tool 消息送回同一模型
  → 模型返回中文反馈 JSON
  → 验证成功后提交评价、反馈与调用记录
  → 网页显示反馈，创业者可查看原文并人工复核
```

本项目调用兼容 chat/completions 的 HTTPS API，使用 messages、tools、tool_calls 和 tool_call_id。供应商必须支持这一协议与工具调用；其他协议需要新增适配器，不能只改密钥就保证可用。

根目录 .env 配置 AI_API_KEY、AI_BASE_URL、AI_MODEL。费率选填，缺少时费用未知。当前已使用用户填写的密钥接通 DeepSeek 官方地址与 deepseek-flash，并完成六类 Agent 实际功能联调；教学质量案例仍须独立验收。接入步骤见 deepseek-setup.md，真实记录见 live-ai-verification.md。配置加载在 backend/config.py；密钥不会返回网页、写入学习记录或导出文件。

## 一次错误辅导如何真的产生行动

示例：学生填写了毛销售额，漏扣退款。

1. 程序 compare_metrics 根据固定交易表发现偏差，保存错误标签 refund 和该提交版本。AI 不计算标准答案。
2. AI 得到提交检查、相关指标口径和该学生已完成的补练。
3. AI 可先调用 check_metrics 读取核验、lookup_skill_card 读取退款知识卡，再调用 assign_remediation，参数为 skill_id=refund、hint_level=1。
4. 后端创建有编号的练习，保存到该学生的 remediation，工具结果返回 AI。
5. AI 输出「先用一笔订单核对退款处理」，引用真实证据。学生能在网页作答补练；程序核验 3×20−15=45 的练习结果。
6. 学生自行修改主任务后重交。原提交和新提交都保留。AI 不能把主任务改为正确，也不能直接把成绩改为通过。

以上工具循环已通过模拟供应商 HTTP 响应的集成测试，包括真实创建练习和回传执行结果；真实模型是否在不同案例中合理选工具仍需实际 API 验收。

## 记忆、证据与版本

SQLite 按学生保存诊断、提交、核验、补练、报告、答辩、迁移、反馈与调用记录。请求只取当前任务上下文，不发送用户名、密码或其他学生的私人内容。知识卡与任务规则在 course.py 版本化维护。

证据具有编号，例如 metric:3:current_net、group:3:channel:线上、report:报告编号、defense:1。上游变更使旧报告失效；旧作品存入历史快照，与新版导出分开。答辩绑定开始时作品快照。

报告评价的 quote 只能出自对应报告的学生正文，evidence_id 必须绑定该报告。答辩评价只能摘录指定答辩回答。编号等系统生成内容不算学生原文。格式与引用校验不等于证明评价正确，因此允许创业者保留原评价后人工复核。

## 提示、权限与输出

每个用途有固定系统提示，告知角色、课程口径、不得捏造、学生材料不能变为系统指令、只允许当前工具。不给模型任意代码执行、数据库语句、文件删除、跨学员读取或支付工具。

报告量表：观察与假设区分、证据、建议可执行性、验证方法、限制说明，五项各 0–5。答辩量表：指标理解、方法解释、限制理解，三项各 0–5。工具参数需具有 criterion、score、reason、quote、evidence_id。

最终回复为：

```json
{"message":"具体中文反馈","evidence_ids":["实际存在的证据编号"],"needs_human_review":false}
```

工具名称、字段、类型、资源和课程状态均要验证。最多三轮工具行动，第四次请求只收最终反馈。正常结束且反馈通过验证才提交草稿副作用；结构错误、服务不可用或超限则放弃草稿，保留原提交、调用记录并申请复核。

## 失败、重复请求与费用

每次供应商请求设 30 秒网络超时，可额外重试一次；一个多轮事件总时长可能超过 30 秒。httpx 的网络超时不是严格的整段事件总时间上限。学生操作期间界面禁用重复提交。

浏览器给每次 POST 生成操作编号；网络重试复用同一编号。服务端按账号、请求内容保存成功响应，并锁住同时到达的同编号操作，避免正常重试重复提交、推进或调用模型。同编号用于不同内容会拒绝。服务进程中断与供应商计费之间仍不能保证外部请求恰好一次。

保存模型标识、动作、是否最终提交、状态、延迟、输入/输出 token、估算费用。超时可能已经计费，遇到未知用量不会显示为免费；已收到的用量另列 reported_usage，最终费用显示未知。运营助理调用也计入工作室总量。

## 没有密钥与接入后的验收

当前基础模式可完成整个学习流程，AI 个性化审阅不生成虚构分数；创业者可查看原文后人工评价。固定问题、知识卡与程序核验明确是基础功能。

你提供密钥、地址和模型标识后，实际验证：连接、工具调用、结构化反馈、完整错误辅导、报告量表、追问、失败回退、用量与账单。再执行 demo-and-pilot.md 的 20 个教练案例；质量达到目标后才邀请真实学生。此状态不能用模拟测试替代。


## 2026-10-12 DeepSeek 真实接入与网页触发

服务读取用户本机 .env 的密钥，实际调用 https://api.deepseek.com/chat/completions，模型 deepseek-flash。非思考模式使用官方 tool_choice 指定当前用途的必要工具：诊断安排下一步；错误反馈安排补练，通过时安排下一步；报告保存五项评价；答辩保存追问或三项评价；作品读取成果；运营读取匿名汇总。模型仍负责生成工具参数、证据摘录和个性化内容，后端验证后执行。

必要工具执行成功后结束工具阶段，用 tool_choice=none、response_format=json_object 和结束阶段系统提示取得最终 JSON。工具参数错误时允许在三轮行动内修正。当前用途提示只包含适用量表，避免报告任务误做答辩评分。必须执行的操作未完成时不能声称成功；失败回滚草稿，保留实际调用与用量，提交物不丢失。

提交诊断、清洗表、指标、分组、报告、开始答辩及保存答辩回答后，网页默认自动请求相应用途的 Agent；保存提交与生成 AI 回馈是两个步骤，AI 失败不撤销已保存提交。用户可关闭自动反馈并手动触发。独立迁移测评不触发 AI 辅导。作品建议及创业者运营分析由用户点击按钮触发。

主画面显示「AI 教练工作记录」：实际中文回馈、执行动作、保存状态、模型、时间与用量；历史从本机数据库读取，刷新仍存在。检查记录见 live-ai-verification.md。本次完成真实功能联调，不代表 20 个教学质量案例或真实学生学习效果已经通过。
