# AI 岗位实战训练营：演示视频拍摄操作表

准备日期：2026-10-13。本文是待执行的拍摄流程；实际执行情况写入文末记录。录屏由参赛者启动、停止和保存，网站由助手操作。

## 录制方式与交接

先录网站操作，再录旁白。操作素材不必限制在十分钟内，最终剪辑按《演示视频文稿》的九分二十秒安排：概述一分四十秒、核心操作五分五十秒、交互与结果一分五十秒。

1. 把网站画面放大到文字清晰。只录网站区域，聊天栏、录屏控制栏和其他软件不纳入画面。
2. 助手完成准备后停在起始画面；参赛者开始录制并回复“已开始录屏”。收到回复前不进行正式拍摄操作。
3. 可以连续录制。助手会在聊天中说明当前段落，这些文字不是视频字幕；剪辑时可用页面标题识别段落。
4. 关键页面至少留五秒；错误窗口、AI回答、新练习、教师草案和核验结果至少留八秒。长内容分屏缓慢滚动，每屏停约五秒。
5. AI处理时不重复点击。保留请求开始、等待提示和结果出现；中间等待可剪短或加速。画面停顿与工具操作间隔也可以剪除。
6. 每段在实际结果可见后才算完成。失败则记录原因，保留失败画面，再修正或另录；不把计划中的成功当成已发生。
7. 录制完成后助手提示停止，参赛者自行停止并检查视频文件。助手无法确认录屏软件是否真的保存成功。

## 逐段操作

### 镜头01：学生项目库与作品概览

用途：概述部分的背景画面，同时为选择项目段落提供素材。

1. 登入演示学生账号。用户名及密码输入过程可以剪掉。
2. 等待项目库出现，停留八秒，保留作品品牌、页面标题及项目卡。
3. 缓慢向下滚动，展示两个已开放项目和其他专业占位项目，每屏停五秒。
4. 如页面有专业筛选，选择一个专业，展示筛选结果，再恢复全部。不要点击尚未开放的占位项目反复尝试。

剪辑保留：项目库全景、两个项目卡、筛选前后。配“学生按专业或兴趣自由选择”的旁白。

### 镜头02：聚光教程

1. 点击页面实际显示的“使用教程”入口；若首次登入自动出现教程，直接使用。
2. 第一页停八秒，展示背景变暗、入口聚焦和说明文字。
3. 点击“下一步”，第二页停八秒。
4. 若说明卡内容超过高度，在说明卡内部缓慢滚动，背景页面保持固定。
5. 点击明确的“跳过”或完成按钮关闭教程，停五秒。

剪辑保留：教程全景、一步切换和说明卡滚动。教程操作不需要覆盖所有步骤。

### 镜头03：进入销售任务并说明起点

1. 点击“销售分析与运营建议”的实际开始或继续按钮。
2. 展示任务导航及诊断、清洗的实际状态，停五秒。
3. 进入指标计算页面，停八秒，让观众看清本次提交位置。
4. 若前置任务未完成，先按页面要求完成，记录为准备操作；后期不要表现为跳过前置仍能直接提交。
5. 如提交页有自动AI反馈开关，首次错误提交暂时关闭，避免提交反馈和主动答疑同时请求。之后需要AI时使用明确入口。

剪辑字幕：此演示学生已完成起点诊断与数据清洗；仅在页面确实显示完成后使用。

### 镜头04：提交漏扣退款的指标

1. 使用页面的指标文件上传入口，选择 `A-metrics-refund-error.csv`。若页面采用手动输入，则逐项填入该文件数据，保持同一份A数据口径。
2. 文件选中或各项填完后停五秒，让观众看见提交内容。
3. 点击实际的“核验指标”或提交按钮一次。
4. 出现未满分或错误反馈窗口后停十秒，保留真实得分和未通过检查项。
5. 如需滚动，先拍窗口上半部分，再拍对应净销售额检查项，每处停八秒。
6. 关闭窗口，保留任务页的实际结果五秒。

手动输入对应值如下。数据来自已准备的A参考CSV，不是现场AI计算的结果：

| 页面字段 | 错误提交 | 修正提交 |
| --- | ---: | ---: |
| 前四周净销售额 | 22890.0 | 22890.0 |
| 后四周净销售额 | 22307.99 | 21160.0 |
| 净销售额变化率（%） | -7.5579 | -7.5579 |
| 后四周净客单价 | 82.9804 | 82.9804 |
| 后四周金额退款率（%） | 5.1461 | 5.1461 |

这里刻意只改错后四周净销售额，其他四项保留参考正确值，以便定位单个检查项。错误值与其他指标不构成一致的完整分析，旁白应称“单个指标漏扣退款的演示错误”。

拍摄要点：这是口径错误的CSV，不是列数损坏的CSV。若出现格式错误，先修正录制准备，不将格式失败配成净销售额核验的旁白。

### 镜头05：主动向AI提问

1. 点击“问AI教练”或该项目实际的Agent答疑入口。
2. 输入以下演示问题，填完停五秒，再发送一次：

> 我直接汇总了每笔订单的数量乘单价，没有减去退款。为什么后四周净销售额没有通过？请解释毛销售额与净销售额的区别，并告诉我应该怎样检查计算步骤。

3. 保留等待提示。AI生成期间不重复发送、不切换任务。
4. 回答出现后先停十秒，再缓慢滚动阅读。重点保留毛额与净额区别、退款处理步骤以及当前任务依据。
5. 如AI调用失败，保留错误提示并记录，不配“AI已成功解答”的旁白。按页面提供的重试入口重试一次，仍失败则暂停此镜头准备。
6. 关闭答疑窗口，回到任务页面。

剪辑保留：输入问题、发送、显眼等待提示和回答重点。AI原文按实际输出录制，不提前替换为固定台词。

### 镜头06：安排与完成针对性练习

1. 展开“我的针对性练习”，停五秒。
2. 点击“让AI安排针对性练习”，保留等待状态。
3. 按实际分支执行：
   - 生成新题：展示题目、针对技能及背景，停十秒。
   - 先追问方法：填写“直接汇总数量乘单价，没有减去退款”；按页面填写真实计算步骤和对应选项，再提交。出现练习后停十秒。
   - 已有未完成练习：展示继续原题的说明，完成原题。后期旁白改为继续当前补练，不能称本次生成了新题。
4. 根据屏幕实际题目计算作答，不把旧参考答案套入新数值。
5. 可以点击一个提示，展示提示后停八秒；若使用AI解释，保留等待及实际解释。
6. 提交答案，展示客观核验结果十秒。若第一次未通过，展示解释、修改和重交，记录实际尝试次数。
7. 确认该练习完成后，再进入教师安排补练的镜头，避免覆盖未完成练习。
8. 若页面有AI协作历史，可展开本次真实读取证据、生成或保存练习的记录，停八秒。

剪辑保留：证据到练习的联系、实际题目、作答与结果。补练完成不等于原任务得分已经修正。

### 镜头07：教师查看同一学生

1. 退出学生账号，登入演示教师账号。剪除身份切换中的输入等待。
2. 展示班级名称、班级码和学生列表，停八秒。
3. 选择查看销售分析项目。班级本身不绑定项目，此处只是切换资料视图。
4. 若主线学生不在班级，先完成加入班级与共享学习证据的准备操作，再重录本段；没有证据时不假称教师已查看。
5. 点击主线学生“查看与指导”，展示本次错误指标与已完成补练，分别停八秒。

剪辑保留：教师身份、同一学生、与前面一致的提交及练习。班级码复制成功窗口可另录五秒作为补充镜头。

### 镜头08：AI教学草案与教师审核

1. 进入“安排补练”，按页面请求AI草案，保留等待提示。
2. 草案出现后，依次展示建议技能、证据依据、难度和给学生的说明，每屏停八秒。
3. 如页面允许编辑，在说明中增加一句：“请先写出毛销售额和退款额，再计算净销售额，并说明每一步使用的字段。”保留修改过程。
4. 只有当前证据有效且没有未完成同技能题时，点击确认发送。
5. 展示实际成功消息八秒。若因证据过期或活跃练习阻止发送，展示实际提示；后期改用“草案审核，尚未发送”，不伪装成已发送。

剪辑保留：AI草案、教师阅读和调整、最终确认状态。

### 镜头09：软件工程任务

1. 切回演示学生账号，返回项目库，进入软件工程。
2. 展示校园活动报名系统任务和阶段导航，停八秒。
3. 展示需求、缺陷复现说明及当前源码版本。明确哪些记录预先完成。
4. 若前置诊断、需求或复现尚未完成，先按参考说明完成；这部分可另存准备素材。
5. 进入源码提交页，选择对应A版本的参考ZIP，停五秒。
6. 点击“运行实际检查”，保留开始、运行中、最终结果。检查等待可以后期加速，不重复启动。
7. 展示当前版本的检查项与实际通过或失败状态，停十秒。
8. 若Docker环境或检查镜像不可用，记录具体提示。本段不称已完成检查；后续补录有效运行，或展示页面可核对的历史检查并注明。

剪辑保留：任务、源码提交、运行状态与一个具体检查项。不能把另一版本的结果配到当前上传版本。

### 镜头10：回到销售任务修正重交

1. 返回项目库，进入主线销售任务的指标页。
2. 选择 `A-metrics-correct.csv`，或手动修正后四周净销售额。其他指标保持原口径。
3. 输入完成后停五秒，点击核验一次。
4. 展示同一检查项本次实际结果十秒。
5. 如有历史记录，展示修改前后的对应版本，每屏停八秒；否则剪辑时使用镜头04和本镜头对照。

剪辑字幕：根据退款口径修正并重新核验。得分及是否通过以屏幕实际结果为准。

### 镜头11：预先完成的作品与学习记录

1. 切换 `agentdemo` 演示记录，打开已完成销售作品。
2. 依次展示图表、分析报告、答辩或学习记录，每页停八秒，长内容只滚动一到两屏。
3. 展示独立迁移记录及其独立作答说明。如果该记录尚未完成，不称已完成独立测评。
4. 打开作品交付页，点击可用的下载入口；下载确认或文件可见后停五秒。
5. 分享链接若需要对外公开，本次优先展示入口，不额外发布个人资料。

全段字幕：预先完成的演示记录。作品只是演示样例，不是刚才几分钟内完成的全部课程。

### 镜头12：结尾背景与补充镜头

1. 返回项目库，停十秒，作为未来方向和结尾旁白背景。
2. 如概述缺少教师、软件工程或AI反馈画面，可利用已录片段，不必重复调用AI。
