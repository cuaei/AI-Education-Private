## 实际发现并修正的问题

1. 旧服务没有载入新密钥：重新启动服务后实际接通。
2. Agent 未获得允许的下一步任务名称：提供准确的 allowed_next_tasks 与 skill_catalog，让工具参数可被系统执行。
3. 报告任务先查询过多知识卡，耗尽行动轮数后继续输出内部调用标记：DeepSeek 请求优先指定当前用途的必要工具；执行成功后停止工具阶段，使用 JSON Output 和结束阶段提示取得最终反馈。
4. 通用提示同时要求报告和答辩量表，导致报告任务试图评价答辩：按用途提供对应量表与范围。
5. 运营反馈没有满分和演示账号口径：匿名数据明确标记客观满分60、演示账号、未计价不等于免费。
6. 只有文字回复却未执行必要动作可能被误当作完成：增加必要操作检查，未执行时拒绝成功结果。
7. 用户本机密钥影响自动测试：测试隔离供应商配置，不使用用户实际密钥。

失败的真实调用保留在记录中；草稿副作用未提交，既有学生提交与原有评价保留。未伪造成功反馈。
