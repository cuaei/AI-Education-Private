# 项目库与统一实训界面

更新日期：2026-10-12。

## 项目选择页

首页说明「选择专业方向 → 查看任务与交付 → 从起点诊断开始」的学习流程。
专业筛选实际过滤项目，可以随时返回「全部」跨专业选择。已开始但未完成的项目显示快捷继续入口。
已开放项目保留任务介绍、交付成果、练习材料、预计投入与真实进度。

目前只有销售分析、软件工程两个可体验实训。教育学、设计、市场营销、旅游管理、外语、会计学、电子信息、新闻传播的八个项目仅为目录占位，标记「筹备中」，无内容或学习进度，按钮停用，不创建实训状态或触发 AI 调用。

## 两个实训共用界面

`frontend/src/TrainingUI.tsx` 提供统一阶段导览、面包屑、进度列、概览标题、能力路径与 AI 工作记录。两类实训各自保留自己的任务、核验方式与独立进度。

AI 面板显示当前反馈、中文行动名称、执行和保存状态，并将历史记录折叠展示。右侧教练区呈现对应项目的交付要求、补练和知识卡。答疑和错误反馈继续使用现有的 `LearningSupport`，独立迁移的协作限制保留。

`frontend/src/workspace.css` 统一字体、卡片、间距和响应式布局。

## 验证范围

已完成 TypeScript / Vite 构建与修改后端文件的语法检查；通过浏览器查看页面呈现。不运行自动行为测试，不使用用户的 API key 发起新 AI 调用。业务评分与提交流程由用户继续人工验收。
