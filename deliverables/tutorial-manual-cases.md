# 聚焦教程人工驗收

新增教程已寫入，以下案例沒有自動執行，實際結果全部待人工驗收。教程不用AI密鑰，不會主動調用模型或提交學生作業。

## 如何開始

刷新本機頁面並登入學生帳號。沒有當前教程版本記錄的新／舊學生帳號，都會收到項目庫邀請。點「開始引導」，逐步閱讀；完成後自己選擇銷售分析或軟件工程，再看該項目的6步教程。

已完成或已跳過的帳號不會反覆彈出。項目庫右上和實訓左側都有「使用教程」，可以重看；離開時保留進行中的步驟，下次顯示續看邀請。創業者與公開分享頁沒有學生教程。

## 案例

| 編號 | 操作／前提 | 預期 | 實際 |
| --- | --- | --- | --- |
| T01 | 用沒有教程記錄的學生帳號登入 | 出現項目庫3步邀請；不自動選項目 | 待人工驗收 |
| T02 | 完成項目庫，再重新整理／重新登入 | 不重播；「使用教程」仍可重看 | 待人工驗收 |
| T03 | 在第2步重新整理 | 提供從第2步繼續及從頭觀看的選擇 | 待人工驗收 |
| T04 | 按「稍後再看」、X或Escape | 保存跳過，下次不強制再播；不改分數／進度 | 待人工驗收 |
| T05 | 完成教程後重看，再中途跳過 | 原完成狀態保留，不因晚到進行中請求重開 | 待人工驗收 |
| T06 | 換另一個學生帳號 | 記錄分開；不能沿用前一帳號的完成狀態 | 待人工驗收 |
| T07 | 先完成銷售教程，再首次進入工程 | 兩課教程分開保存；工程顯示自己課程的文字 | 待人工驗收 |
| T08 | 沒做起點診斷時進課程教程 | 解釋診斷、逐題作答和提交；不要求立即上傳CSV／ZIP | 待人工驗收 |
| T09 | 已有進度或已完成課程時開始教程 | 切到本人當前已解鎖任務／作品，不重置成績 | 待人工驗收 |
| T10 | 当前沒有材料、灰色提交按鈕、没有回饋 | 说明前提，聚焦實際區域，不製造假回饋或解鎖任務 | 待人工驗收 |
| T11 | 銷售資料階段／工程源碼階段重看 | 分步說明檔案操作，解釋CSV、UTF-8、ZIP及源碼；工程明确上傳後還需運行檢查 | 待人工驗收 |
| T12 | 逐步閱讀教材 | 每步都有位置說明、操作列表、概念完整句子和結果，不靠一句口號解釋多個動作 | 待人工驗收 |
| T13 | 同時出現AI等待、真實錯誤／提交彈窗或答疑 | 教程與暫停橫幅撤下，真實內容可操作；聊天輸入焦點不被反覆搶走；結束後自行點繼續 | 待人工驗收 |
| T14 | 手機尺寸、視窗縮放、页面捲動 | 聚焦位置重算；横屏或200%縮放時整卡可捲動，正文與操作按鈕仍可達 | 待人工驗收 |
| T15 | 只用鍵盤上一步、下一步、跳過 | 焦點限制在教程內；關閉後背景恢復可操作，焦點回入口或當前任務 | 待人工驗收 |
| T16 | 系統開啟減少動態效果 | 不平滑捲動或旋轉動畫，仍能識別聚焦區域 | 待人工驗收 |
| T17 | 保存時斷線／服務不可用，或快速雙擊 | 明確報錯、保留本步、可重試，不空白跳頁或聲稱已保存 | 待人工驗收 |
| T18 | 工程／銷售獨立階段重看 | 说明針對答案的輔導限制，不自動切協作、發問或提交 | 待人工驗收 |
| T19 | 多頁簽，一頁完成／跳過後另一頁晚寫進度 | 終止狀態保留，不重新開啟首次邀請 | 待人工驗收 |
| T20 | 創業者登入、查看公開作品 | 沒有學生教程，也不載入私人教程記錄 | 待人工驗收 |
| T21 | 教程歡迎卡／每一步：在遮罩和聚焦區用滾輪、觸控、PageDown；再捲動說明卡到頂／底；最後跳過、完成或因真實彈窗暫停 | 用戶不能捲動網站背景；只可捲動教程內容，頂／底不帶動背景。下一步可由系統自動定位，說明從頭顯示；教程關閉或暫停後恢復正常捲動 | 待人工驗收 |

保存結果時請記錄帳號匿名標識、項目、教程版本、步驟及錯誤畫面。不要把構建或啟動成功填成上述行為案例已通過。
